# Enhancement Suggestions

These are ideas to improve the Sasa POS system based on my testing:

## 1. Better Login Security
- Add real username and password checking
- Lock account after 3 failed attempts
- Show "Invalid credentials" message

## 2. Group Repeated Items
- Instead of showing "Pap, Pap, Pap" show "Pap x3"
- Easier to read, less scrolling

## 3. Order Confirmation Details
- Show date and time of order
- Show order number clearly
- Option to print or email receipt

## 4. Better User Messages
- Instead of just "Added Pap" maybe "Pap added to order — R23.00 total"
- Helps cashier confirm the right thing happened
