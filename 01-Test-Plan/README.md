# Test Plan & Scope

## Purpose
To check that the Sasa POS frontend works correctly for basic restaurant ordering tasks.

## What I Tested (In-Scope)
1. **Login** — Can users sign in and reach the dashboard?
2. **Menu Selection** — Can users click food items and see them in the order?
3. **Order Management** — Can users add, clear, and confirm orders?
4. **Price Calculation** — Does the system add prices correctly and apply 15% VAT?
5. **UI Behavior** — Do buttons work? Is the layout correct?

## What I Did NOT Test (Out of Scope)
- Real backend login validation (system is in demo mode)
- Saving orders to a database
- Payment processing
- Connection to kitchen/staff systems
- Speed or security testing

## How I Tested
- Manually, by clicking through the app like a real user
- Following written test cases step by step
- Taking screenshots of results
